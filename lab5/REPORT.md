## Theory

A Context-Free Grammar (CFG) is a 4-tuple `G = (V_N, V_T, P, S)` where `V_N` is the set of non-terminal symbols, `V_T` is the set of terminal symbols, `P` is the set of production rules, and `S` is the start symbol.

Chomsky Normal Form (CNF) is a restricted form of CFG where every production rule takes one of exactly two shapes:

- `A to BC` — a non-terminal produces exactly two non-terminals
- `A to a` — a non-terminal produces exactly one terminal

Any context-free language (except those containing ε) can be expressed by a grammar in CNF. Converting to CNF is useful because it enables efficient parsing algorithms such as the CYK (Cocke–Younger–Kasami) algorithm, which runs in O(n³) time and requires the grammar to be in CNF.

The conversion process involves five normalization steps applied in order, each of which preserves the language generated by the grammar.

## Implementation Description

The entire implementation lives in a single file: `cnf_converter.go`. The core data structure is a `Grammar` type, and the five normalization steps are implemented as methods on it. A utility `ConvertToCNF` function chains all five steps and reports results at each stage.

### Grammar Representation

```go
type Grammar struct {
    VN    map[string]bool
    VT    map[string]bool
    P     map[string][]string

}
```

`VN` and `VT` are sets represented as `map[string]bool`. Productions `P` map each left-hand side non-terminal to a slice of right-hand side strings, where each string is a concatenation of symbol tokens (e.g. `"AbB"` means the sequence `A`, `b`, `B`).

Symbols are parsed from these concatenated strings by `parseRHS`, which distinguishes non-terminals (uppercase letter optionally followed by digits) from terminals (any other single character):

### Step 1 — Eliminate ε-Productions

First, compute the set `N_ε` of all nullable non-terminals — those that can derive the empty string directly or transitively:

```go
nullable := make(map[string]bool)
// seed: any A to "" directly
// then fixed-point: if all symbols of some rhs are nullable, so is lhs
for changed := true; changed; { ... }
```

Then rebuild the production set. For every rule `A → X₁X₂...Xₙ`, generate all combinations where nullable symbols are optionally omitted — except the empty combination:

```go
for mask := 0; mask < (1 << n); mask++ {
    // skip nullable positions according to bitmask
    // if the resulting string is non-empty, add it
}
```

### Step 2 — Eliminate Renaming (Unit Productions)

A unit production is a rule of the form `A to B` where `B` is a single non-terminal. The step computes, for each non-terminal `A`, the set `R(A)` of all non-terminals reachable from `A` via chains of unit productions:

```go
reachable[nt] = map[string]bool{nt: true}
for changed := true; changed; {
    // if A to * B via units and B to C via unit, add C to R(A)
}
```

Then the new production set for `A` collects every non-unit rule from every `B contains R(A)`:

```go
for nt := range g.VN {
    for reachNT := range reachable[nt] {
        for _, rhs := range g.P[reachNT] {
            if len(syms) == 1 && g.VN[syms[0]] { continue } // skip units
            newP[nt] = addUniq(newP[nt], rhs)
        }
    }
}
```

### Step 3 — Eliminate Inaccessible Symbols

Starting from the start symbol `S`, a reachability closure identifies every symbol that can actually appear in a sentential form:

```go
accessible := map[string]bool{g.Start: true}
for changed := true; changed; {
    // for every accessible lhs, mark all symbols in its rhs as accessible
}
```

Any non-terminal not in `accessible` is removed from `V_N`, its productions removed from `P`, and any rule referencing it is also dropped.

### Step 4 — Eliminate Non-Productive Symbols

A symbol is productive if it can eventually derive a string of terminals. Terminals are productive by definition; non-terminals are productive if at least one of their productions consists entirely of productive symbols:

```go
productive := make(map[string]bool)
for t := range g.VT { productive[t] = true }
for changed := true; changed; {
    // A is productive if some rhs has all productive symbols
}
```

Non-productive non-terminals and any rules referencing them are removed.

### Step 5 — Convert to CNF

This step has two sub-passes.

**Part a — Isolate terminals in long rules.** For every rule of length ≥ 2 that contains a terminal `a`, introduce a fresh non-terminal `Xₙ` with the unit rule `Xₙ to a` and replace every occurrence of `a` in long rules with `Xₙ`:

```go
if ng.VT[s] {
    if _, ok := termNT[s]; !ok {
        nt := fmt.Sprintf("X%d", counter)
        termNT[s] = nt
        newP[nt] = addUniq(newP[nt], s)
    }
    newSyms[i] = termNT[s]
}
```

**Part b — Break long rules.** Any rule `A to X₁X₂...Xₙ` with n > 2 is broken into a chain of binary rules by introducing fresh non-terminals `Yₙ`:

```
A → X₁ Yₙ
Yₙ → X₂X₃...Xₙ
```

This loop repeats until no rule has more than 2 symbols:

```go
for {
    changed := false
    // scan all rules; if len > 2, split and set changed = true
    if !changed { break }
}
```

### CNF Verification

After conversion, `IsCNF()` validates the result by checking every rule against the two allowed CNF shapes:

```go
func (g *Grammar) IsCNF() bool {
    for _, prods := range g.P {
        for _, rhs := range prods {
            syms := parseRHS(rhs)
            switch len(syms) {
            case 1:
                if !g.VT[syms[0]] { return false }
            case 2:
                if !g.VN[syms[0]] || !g.VN[syms[1]] { return false }
            default:
                return false
            }
        }
    }
    return true
}
```

### Full Pipeline

```go
func ConvertToCNF(g *Grammar) {
    g.Print("original grammar")
    g1 := g.Step1(); g1.Print("done step 1")
    g2 := g1.Step2(); g2.Print("done step 2")
    g3 := g2.Step3(); g3.Print("done step 3")
    g4 := g3.Step4(); g4.Print("done step 4")
    g5 := g4.Step5(); g5.Print("final Chomsky Normal Form")
    if g5.IsCNF() {
        fmt.Println("is valid Chomsky Normal Form")
    }
}
```

## Example Cases

### Variant 14 Grammar

**Input grammar:**

| Non-terminal | Productions |
|---|---|
| S | aB, A |
| A | bAa, aS, a |
| B | AbB, BS, a, ε |
| C | BA |
| D | a |

**Step 1 — Remove ε-productions:**

`N_ε = { B }`. Every rule containing `B` gains a copy with `B` omitted. `B → ""` itself is dropped.

**Step 2 — Remove unit productions:**

`R(B) = { A, B, S }`, `R(S) = { A, S }`. The unit rule `S → A` is replaced by all non-unit productions of `A`.

**Step 3 — Remove inaccessible symbols:**

`C` and `D` are never reachable from `S`. Both are removed.

**Step 4 — Remove non-productive symbols:**

All remaining symbols are productive — no change.

**Step 5 — Convert to CNF:**

Two terminal wrappers are introduced: `X1 to b`, `X2 to a`. Binary-rule splitting introduces `Y3`, `Y4`, `Y5`, `Y6` to break three-symbol rules. Final grammar:

```
A  → X1 Y6 | X2 S | a
B  → A Y3  | A X1 | B S | a | X2 B | X1 Y4 | X2 S
S  → X2 B  | a    | X1 Y5 | X2 S
X1 → b
X2 → a
Y3 → X1 B
Y4 → A X2
Y5 → A X2
Y6 → A X2
```

`IsCNF()` returns `true`.

### Bonus — PDF Example Grammar

**Input grammar:**

| Non-terminal | Productions |
|---|---|
| S | AC, bA, B, aA |
| A | ε, aS, ABAb |
| B | a, AbSA |
| C | abC |
| D | AB |

**Step 1:** `N_ε = { A }`. Rules containing `A` gain copies with it omitted.

**Step 2:** `R(D) = { B, D }`, `R(S) = { B, C, S }`. Unit productions expanded and removed.

**Step 3:** `D` becomes inaccessible after expansion and is removed.

**Step 4:** `C` is non-productive (it only derives strings with `C` again, never pure terminals). Removed.

**Step 5:** Terminal wrappers `X1 to a`, `X2 to b` and binary-split helpers `Y3`–`Y14` reduce all rules to CNF shape.

`IsCNF()` returns `true`.

## Conclusions

The five-step normalization pipeline converts any CFG into Chomsky Normal Form in a predictable, mechanical way. Each step has a well-defined precondition and postcondition, which means they can be verified and tested independently — the `Print` call after each step makes intermediate grammars fully visible.

Using a fixed-point loop (repeat until `changed == false`) for steps 1, 2, 3 and 4 correctly handles transitive cases — for example, a nullable non-terminal that only becomes nullable because another nullable non-terminal is in its right-hand side.

The bitmask enumeration in Step 1 cleanly generates all subsets of nullable positions without recursive calls, and the fixed-point binary-splitting loop in Step 5b guarantees termination because each iteration strictly reduces the maximum rule length by at least one symbol.

The bonus requirement — accepting any grammar — is satisfied: `NewGrammar` takes its non-terminals, terminals, start symbol and productions as parameters, so `ConvertToCNF` works on any CFG passed to it, as demonstrated by both the Variant 14 grammar and the PDF example.
